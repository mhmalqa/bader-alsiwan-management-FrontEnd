# تسليم الخلفية

التدفق المالي المرجعي: `LeaseContract → Receivable → Payment → management fee → owner expense → OwnerSettlement → OwnerTransfer → remaining balance`.

السيناريو الثابت في Mock Data هو عقد سنوي 120,000 ريال بأربعة أقساط 30,000؛ أول قسط محصل، رسوم إدارة 5% = 1,500، مصروف مالك 2,000، صافي مستحق 26,500، تحويل 20,000، ورصيد 6,500.

استبدل وحدات `services/` بطبقات API متوافقة مع نفس الواجهات async. المصادقة المستقبلية خاصة بالموظفين فقط؛ Owner وTenant سجلات أعمال وليسا مستخدمين. الصلاحيات يجب أن تنفذ في الخلفية، والواجهة لا تعد بديلاً عن ذلك.
